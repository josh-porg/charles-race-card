Data branch for the Lake Whatcom conditions page: `live.json` (the lakeside CWOP weather stations' last few hours,
refreshed every 15 minutes by `.github/workflows/whatcom-relay.yml` on main, from findu.com) and `history/` (every
reading since 27 Aug 2026, for recalibrating the lake wind model). Public weather-station data; stations named by place.
